# 命令行数据清洗流水线 

## 1. 项目简介
本项目是一个基于 Python 和 Pandas 构建的命令行数据清洗工具。旨在处理原始数据中常见的脏数据，包括：编码异常、缺失值、重复行以及非法值过滤。

## 2. 运行环境
- Python 版本: 3.9 及以上（当前测试环境: Python 3.12）
- 第三方依赖: `pandas`, `numpy`

## 3. 安装与运行

### 3.1 安装依赖
在终端执行以下命令安装所需库：
```bash
pip install -r requirements.txt
```

### 3.2 运行命令
使用 main.py 提供命令行接口。参数说明：
* --input: 输入脏数据的文件路径 (必填)
* --output: 清洗后数据的输出路径 (必填)

运行示例
```bash
python src/main.py --input data/raw/dirty_data.csv --output data/processed/clean_data.csv
```
## 4. 清洗规则说明
本工具在 src/cleaner.py 中实现了以下核心清洗逻辑：

1. 编码容错：默认使用 UTF-8 读取，若失败自动降级尝试 GBK 编码。

2. 缺失值处理：删除关键字段（如 id）缺失的行；非关键字段（如 name）填充为 'Unknown'。

3. 重复值处理：使用 Pandas 自动丢弃完全重复的行。

4. 非法值处理：将 age 字段强制转换为数值型，并过滤掉不在 0 - 120 合理范围内的异常值；将 date 字段通过 pandas 进行非法值过滤。

## 5. 异常处理与退出码
- 成功执行：程序正常处理数据并返回退出码 0。

- 失败退出：若输入文件不存在、格式错误或发生未知异常，程序会捕获异常并打印友好报错信息，同时返回退出码 1。

- 空文件处理：若读取到空文件，程序会触发 Pandas 异常，被 try-except 捕获并安全退出。
